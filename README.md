# 🎨 Gmail Claymate Theme Manager

A modern, tactile, and beautifully crafted Chrome extension that transforms your Gmail experience into a soft, "Claymorphic" masterpiece. Choose between four distinct palettes and enjoy a calming, 3D-like interface.

---

## ✨ Features

- **Claymorphic UI**: Soft, rounded elements with deep inner and outer shadows for a tactile, "inflated" 3D look.
- **Theme Manager**: Instant switching between 4 unique themes without refreshing the page.
- **Full Coverage**: Consistent styling across the Inbox, Message View, Compose Window, and Search bars.
- **Persistent Choice**: Your selected theme is saved to your profile and applies automatically every time you open Gmail.
- **Modern Palette**: Carefully chosen colors that are easy on the eyes.

## 🚀 How to Install

1. **Clone or Download**: Download this repository as a ZIP and extract it.
2. **Open Extensions**: In Chrome, navigate to `chrome://extensions/`.
3. **Developer Mode**: Enable "Developer mode" in the top right corner.
4. **Load Extension**: Click **Load unpacked** and select the project folder.
5. **Customize**: Click the extension icon in your toolbar to switch themes instantly!
