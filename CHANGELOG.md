# 📝 Gmail Claymate Theme Manager - Release Changelogs

Here are the detailed changelogs for each version of the extension to use for your GitHub Releases.

---

## 🚀 v2.3 (Current)
### **What's New**
- **Blue Sky Theme**: Replaced the "White Milk" option with a fresh and calming sky blue palette.
- **Black Metal Fix**: Significantly improved text contrast and visibility for dark mode users.
- **Organization Link**: Updated the extension footer to point directly to the [TSunOrganization/Gmail-Theme-Manager](https://github.com/TSunOrganization/Gmail-Theme-Manager) repository.
- **Emoji Fix**: Fixed the heart emoji encoding in the footer for a perfect ❤️ display.
- **Version Bump**: Officially updated the extension to version 2.3.

---

## 🎨 v2.2
### **What's New**
- **Black Metal Refinement**: Initial adjustments to the dark mode palette.
- **Theme Selection UI**: Added visual indicators (green border/highlight) in the popup to show which theme is currently active.
- **Stability**: Added `MutationObserver` to ensure styles stay applied even when Gmail dynamically reloads content.

---

## ⚡ v2.1
### **What's New**
- **Instant Theme Switching**: Implemented real-time CSS injection so users don't need to refresh Gmail to see theme changes.
- **Confirmation Messages**: Added a small "Applied!" status message in the popup when a theme is selected.
- **Bug Fixes**: Resolved issues where styles were not applying correctly to the Search bar and Header buttons.

---

## 🛠️ v2.0
### **What's New**
- **Theme Manager Transformation**: Converted the static extension into a full Theme Manager.
- **Popup UI**: Created a beautiful, tactile popup with 4 color circles for easy customization.
- **Persistent Storage**: Integrated `chrome.storage.sync` to save user theme choices across sessions and devices.
- **Social Branding**: Added a footer with links to GitHub, Instagram, and Telegram, along with the "Created With ❤️ By TSunStudio" credit.

---

## 🟢 v1.8
### **What's New**
- **Full Gmail Coverage**: Extended styling to the **Message View** (opened emails) and the **Compose Window**.
- **Tactile Inputs**: Added claymorphic inset shadows to the email editor and search fields.
- **Clean UI**: Removed unnecessary borders and lines for a more minimal look.

---

## 🌿 v1.5
### **What's New**
- **Green Claymate Palette**: Updated the primary theme from Cream to a soft Sage Green aesthetic.
- **Refined Shadows**: Adjusted inner and outer shadow depths for a more realistic clay look.
- **Button Animations**: Added hover scaling effects to the Compose button for better interactivity.

---

## 🍦 v1.0
### **What's New**
- **Initial Release**: Launched the **Claymate Cream** aesthetic for Gmail.
- **Core Claymorphism**: Implemented the base CSS for rounded corners and 3D-like shadows.
- **Icon Set**: Created the first set of clay-style extension icons (16px, 48px, 128px).
